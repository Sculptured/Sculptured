---
title: Older team files
description: sculptured.team/v1, the JSON format Sculptured saved teams in before team files became MADL documents.
---

Until 19 October 2026, **Export team file** saved a `.sculptured-team.json` file in the `sculptured.team/v1` format. Team files are now [MADL](/guides/madl) documents (`.madl.yaml`). Import still reads the older files, so nothing you exported before is lost; export writes MADL only.

To turn an older file into MADL, import it (**New project** → **Advanced: import a team file or a past run**), then export the new team with **Export team file**.

| | |
| --- | --- |
| Format string | `sculptured.team/v1` |
| File name | `<team>.sculptured-team.json` |
| Read by | Import |
| Written by | Nothing, since 19 October 2026 |

An older file is one JSON object:

| Field | What it holds |
| --- | --- |
| `format` | `"sculptured.team/v1"` |
| `$schema` | The schema address it was written with; ignored |
| `team` | The team as the board held it: agents, groups, arrows, the workflow, positions |
| `settings` | `posture` (`restricted` or `unrestricted`), `own_copies`, `question_timeout_min` |

Its JSON Schema is no longer published. For the fields of today's files, see [MADL files](/guides/madl) and [MADL's specification](https://github.com/Sculptured/Multi-Agent-Descriptor-Language/tree/main/spec/draft).
